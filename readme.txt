== Description ==

Elementify is a sleek and minimalist WordPress blog theme, thoughtfully designed to help you build a visually captivating blog. Whether you're sharing content about fashion, travel, music, cars, real estate, beauty, design, food, weddings, movies, photography, technology, or personal stories, Elementify adapts beautifully to any niche. With its clean layout, refined typography, and unique styling, the theme puts your content front and center, offering an elegant reading experience your audience will love.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.

== Frequently Asked Questions ==

= Does this theme support any plugins? =

Elementify includes styles for WooCommerce shop, product, cart, checkout and account pages.

= Does the theme add structured data? =

Yes. Elementify describes the header, navigation, sidebar, footer, posts, authors, comments and breadcrumbs with schema.org microdata. If an SEO plugin already prints a complete schema graph, turn it off under Appearance > Customize > Schema Markup.
